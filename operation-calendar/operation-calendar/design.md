# 运营日历（Operation Calendar）— 功能设计方案

> 版本：v1.0 | 日期：2026-07-15 | 状态：设计中

---

## 一、背景与目标

当前运营平台已具备**数据看板**和**故障监测**两大模块，运营数据通过飞书 API 导入，存储于 `store` 中。现计划新增一个**运营日历**页面，以月历视图直观展示每日各站点的运营情况，并支持手动标注和备忘录功能。

### 核心需求

1. **月历视图**：标准月历布局（周日~周六），支持鼠标滚轮和键盘方向键切换月份
2. **每日概览**：方格底部显示当天有情况的站点色块，悬浮弹出当日各站点概况
3. **右侧备忘录**：实时展示本月有记录的站点，每个站点显示最近 5 条消息，支持滚动和单站详情
4. **编辑模式**：点击方格进入当日编辑，飞书数据只读展示，支持手动新增站点状态（置顶）
5. **置顶机制**：手动添加的内容在悬浮 tooltip 和备忘录中始终优先展示

## 三、数据模型

### 3.1 日历每日数据结构

```javascript
{
  "2026-07-15": {
    // 飞书导入的原始数据（运行时从 store 聚合，只读）
    "feishuItems": [
      {
        "station": "104",
        "faultType": "本体故障",
        "occurTime": 1721000000000,
        "reason": "...",
        "category": "..."
      },
      {
        "station": "兴发",
        "faultType": "传感器故障",
        "occurTime": 1721000000000,
        "reason": "..."
      }
    ],
    // 手动添加/编辑的数据（持久化到 calendar_data.json，置顶层）
    "manualItems": [
      {
        "id": "uuid-xxx",
        "station": "104",
        "status": "正常运营",
        "note": "全天无异常，设备运行稳定",
        "addedAt": 1721000000000,
        "pinned": true
      }
    ]
  }
}
```

### 3.2 备忘录聚合数据

```javascript
{
  "stations": ["104", "兴发", "嘉兴", "波然"],   // 本月有记录的站点（按最近活跃排序）
  "messages": [
    {
      "station": "104",
      "date": "2026-07-15",
      "text": "状态：正常运营",
      "source": "manual",        // "manual" | "feishu"
      "time": 1721000000000,
      "pinned": true
    },
    {
      "station": "104",
      "date": "2026-07-15",
      "text": "本体故障 ×1",
      "source": "feishu",
      "time": 1721000000000,
      "pinned": false
    }
  ]
}
```

### 3.3 存储方案

| 数据 | 存储位置 | 说明 |
|------|----------|------|
| 飞书问题记录 | 运行时从 `store` 聚合 | 不重复存储，每次渲染时实时计算 |
| 手动标注 | `calendar_data.json` | 服务端持久化，key 为日期字符串 |
| 备忘录消息 | 前端内存聚合 | 从日历数据 + store 拼装 |

## 四、交互设计

### 4.1 日历基础交互

| 操作 | 行为 |
|------|------|
| 点击 `<` `>` 箭头 | 切换到上/下个月 |
| 鼠标滚轮 | 上滚 → 上月，下滚 → 下月 |
| 键盘 `←` `→` | 切换到上/下个月 |
| 今天 | 高亮显示（`--accent` 色边框或背景） |
| 非当前月日期 | 灰色淡化显示 |

### 4.2 悬浮 tooltip

- 鼠标移入方格 → 200ms 延迟后弹出 tooltip
- tooltip 定位跟随鼠标，自动调整避免溢出视口
- 内容按 `pinned` 排序，手动标注置顶并带 📌 图标
- 鼠标移出 → tooltip 消失

### 4.3 右侧备忘录

- **默认视图**：显示本月有记录的站点列表，每个站点展开最近 5 条消息
- **消息排序**：按时间倒序，手动标注（pinned）置顶
- **滚动加载**：每个站点消息区支持独立滚动，滚动到顶部自动加载更早消息
- **单站视图**：点击某站点 → 仅显示该站点消息，支持"查看本月之前"加载历史
- **返回按钮**：单站视图下提供 `← 返回全部站点` 按钮
- **实时更新**：编辑模式下新增内容后，备忘录即时刷新

### 4.4 编辑模式

- **入口**：点击日历方格
- **模态框布局**：
  ```
  ┌──────────────────────────────┐
  │ 7月15日 编辑                     [×] │
  │                              │
  │ ── 飞书导入记录 ──            │
  │ 兴发 | 本体故障 | 14:30 | ... │  ← 只读列表
  │ 嘉兴 | 平台故障 | 16:00 | ... │
  │                              │
  │ ── 手动标注 ──        [+ 新增] │
  │ 📌 104站 | 正常运营 | [删除]   │  ← 可删除
  │                              │
  │ [+ 新增站点状态]              │  ← 展开表单
  │   站点: [▼ 选择站点]          │
  │   状态: [▼ 正常运营/异常/停机] │
  │   备注: [______________]     │
  │   [保存] [取消]              │
  └──────────────────────────────┘
  ```
- **规则**：
  - 飞书数据只读，不可编辑或删除
  - 手动标注可新增、可删除
  - 同一站点同一天可以有多个手动标注（追加而非覆盖）
  - 新增后立即置顶，tooltip 和备忘录同步刷新

## 五、后端 API

| 方法 | 路径 | 用途 |
|------|------|------|
| `GET` | `/api/calendar?month=2026-07` | 获取整月每日聚合数据（飞书 + 手动） |
| `GET` | `/api/calendar/{date}` | 获取某天详情 |
| `POST` | `/api/calendar/{date}/manual` | 新增手动站点状态 |
| `DELETE` | `/api/calendar/{date}/manual/{id}` | 删除某条手动标注 |
| `PUT` | `/api/calendar/{date}/manual/{id}` | 修改某条手动标注 |

### 请求示例

```http
POST /api/calendar/2026-07-15/manual
Content-Type: application/json

{
  "station": "104",
  "status": "正常运营",
  "note": "全天无异常"
}
```

### 数据存储

新增 `calendar_data.json`：

```json
{
  "2026-07-15": {
    "manualItems": [
      {
        "id": "a1b2c3d4",
        "station": "104",
        "status": "正常运营",
        "note": "全天无异常",
        "addedAt": 1721000000000
      }
    ]
  }
}
```
