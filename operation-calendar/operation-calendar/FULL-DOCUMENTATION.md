# 运营日历 — 使用说明

> V4.0.0 —— 月历改为周视图（站点 × 日期矩阵）

---

## 一、入口

左侧导航栏 **运营记录** → 卡片顶部切换 **日历视图**。

原来独立的「📅 运营日历」导航项已移除：日历不再是单独页面，而是运营记录的第二个视图，和 **列表视图** 共用同一份数据。

---

## 二、整体形态

横轴是一周 7 天（**周一起算**，与运营周报的统计周口径一致），纵轴是站点。一个格子 = 一个站点的一天。

```
◀  2026年7月 · 第31周   07/27 - 08/02  ▶  [本周]        [站点 7/9 ▾]  图例
┌────────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│ 站点   │周一27│周二28│周三29│周四30│周五31│周六01│周日02│
├────────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ ●104   │▏6.7h │▏7.2h │▏检修 │  —   │  —   │  —   │  —   │
│        │▏101  │▏118  │      │      │      │      │      │
├────────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ ●兴发  │▏5.1h │▏6.0h │▏6.3h │ …                          │
└────────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
```

表头吸顶、站点列吸左，站点多或横向滚动时都不会丢失定位。

## 三、单元格：四种状态

状态靠格子左侧 3px 色条 + 极淡底色表达，格内只放数字，鼠标悬浮出完整信息。

| 状态 | 判定条件 | 色条 | 格内显示 |
|---|---|---|---|
| **运营 · 有生产** | 有运营记录，且 自动生产上料 + 人工上料 > 0 | 绿 | 上行 `运营时长`，下行 `自动上料总数` |
| **运营 · 无生产** | 有运营记录，但上料为 0 | 灰 | 同上（上料数为 0） |
| **未运营** | 有未运营记录 | 橙 | 未运营原因（橙字，最多两行，超长截断） |
| **无记录** | 当天该站点没有任何记录 | 无 | 灰色 `—` |

- 运营时长取自「总运营时间（分钟）」÷ 60，与列表视图、看板同一套计算口径（`calc()`）
- 未运营原因超长时格内截断，**鼠标悬浮显示全文**
- 今天所在的整列有淡橙底色，表头日期变橙并带下划线

**点击交互**：

- 点已有记录的格子 → 打开该条记录的详情
- 点空格子（`—`）→ 打开新增弹窗，**已预填该站点和该日期**

## 四、周切换

四种方式，效果相同：

- 工具栏 **◀ ▶** 按钮
- **本周** 按钮回到当前周
- 键盘 **← →**（光标在输入框内时不触发）
- **鼠标滚轮**（表格自身还能上下滚时先滚表格，滚到边界才翻周）

跨月的那一周，标题显示 `2026年7月-8月`；跨年显示 `2026年12月 - 2027年1月`。标题后的「第 N 周」是 ISO 周序号。

---

## 五、站点筛选

工具栏右侧 **站点 7/9 ▾**（当前显示 7 个 / 共 9 个）：

- 勾选 / 取消勾选控制该站点是否出现在纵轴
- **全选** / **清空** 批量操作
- 点面板外任意位置收起
- 选择结果存在浏览器本地，**刷新页面后保持**；之后新增的站点默认可见

站点列表 = 站点管理里的站点 **∪** 数据中出现过的站点。取并集是为了让站点管理里已删除的站点，其历史数据仍然看得到。

---

## 六、数据来源

日历视图和列表视图**完全同源**，都读 `data.json`：

- **运营记录** —— 原有格式不变
- **未运营记录** —— 同一个文件，靠 `noOp: true` 字段区分，只带 `站点 / 日期 / 原因`，**不写任何指标字段**

所以：在日历上点空格子新增的记录，立刻出现在列表视图；在列表视图删掉一条，日历上对应格子立刻变回 `—`。

**未运营记录不会污染任何统计**。运行时它们被装在独立的集合里，看板、运营周报、故障分析、AI 分析、Excel 导出读到的始终只有运营记录。即便某个统计路径漏了过滤，未运营记录因为完全没有指标字段，算出来是空值而不是 0，也不会拉低分母。

---

## 七、录入未运营记录

新增 / 编辑弹窗右上角勾选 **无运营**：

- 指标相关的全部区块（上料统计、时长统计、故障统计、自动计算指标、问题记录、备注）与「从统计工具拉取数据」按钮一并隐藏
- 只保留 **站点 / 日期 / 无运营原因**
- 原因**必填**，不填直接保存会被拦下
- 取消勾选即回到普通运营记录录入

列表视图里，未运营行的站点后面带一枚「未运营」徽章，指标列合并显示原因。

---

## 八、本版移除的功能

以下月历时代的功能已随重构一并移除：

- 农历与节日显示
- 三级备注（每日备注 / 站点手动备注 / 全站月度备注）
- 月度异常一览右侧面板
- 日详情悬浮面板（含手动添加站点状态、+ 站点）
- 独立的 `/api/no-op-records` 接口（未运营记录改走 `/api/records`）

历史备注数据未删除：后端 `/api/calendar/notes` 与 `calendar_data.json` 保留原样，只是界面上不再有入口。
