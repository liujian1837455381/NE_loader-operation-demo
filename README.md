# Loader Ops Frontend Demo

这是一个用于暑期实习 AI Coding 成果展示的静态前端项目，仅用于演示与展示，不包含真实生产数据。

## 已包含

- 运营看板展示
- 运营周报展示
- 生产监测展示
- 故障监测展示
- 站点管理与日历视图
- 本地 mock 数据驱动
- 可直接部署到 GitHub Pages

## 启动方式

在本目录下执行：

```powershell
python -m http.server 8787
```

然后在浏览器中打开本机 `8787` 端口下的 `index.html`。

## 说明

- 不连接真实后端
- 不包含真实访问凭据
- 所有数据均为演示构造
- 适合作为静态网页成果展示
